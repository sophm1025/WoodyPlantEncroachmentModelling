# Data

The CSV files in this folder are tracked with Git LFS in the original repository.
They include datasets for SRER and JORN across 2017 and 2021 plus model prediction outputs.

If you clone the repository and the CSVs appear as very small pointer files, install Git LFS and run:

```bash
git lfs install
git lfs pull
```

Large source datasets are not duplicated across notebook folders; each dataset is stored once here.
