# Notebook Organization

- `eda/`: exploratory analysis and visualization.
- `models/core/`: general classification/model-comparison notebooks.
- `models/tree_based/`: decision trees, bagging, random forest, and related cross-validation studies.
- `models/boosting/`: XGBoost, LightGBM, CatBoost, ROC, and boosting-focused experiments.
- `validation/`: cross-site and cross-year transfer experiments, grouped by which site acts as the validation target.
